The Challenge

A meaningful proportion of users may be living with sight loss, so accessibility could not be treated as a feature add-on. It had to be a primary constraint from discovery through QA.

Testing surfaced issues in mission clarity, impact storytelling, and terminology-driven navigation.

+70%Donations page traffic
+£10kDonation income, year one

The Solution

The team designed four distinct user journeys within one coherent IA, with accessibility controls surfaced directly in navigation and reinforced through component behavior.

  • High contrast mode toggle as core MVP navigation element
  • Global text sizing controls tested against real user needs
  • A-Z condition architecture designed for screen readers and keyboard users
